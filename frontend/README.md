# 工作台前端

Vue 3、TypeScript、Vite。业务记录全部来自后端，不包含演示任务、假统计或固定运行结果。

2026-09-17已完成浅色毛玻璃界面与接入简化：程序库一次上传并连续发布、执行电脑下载连接文件、输入文件一次多选提交；任务默认选择可用已发布版本，参数和执行规则放入高级设置。见[操作说明](../docs/usability-simplification.md)和[75项前端/双实例浏览器验收](../docs/testing/usability-redesign-report.md)。

## 本地开发

1. 使用满足当前 Vite 要求的 Node.js（已验证 Node 24.18.0）。
2. 在本目录运行 `npm ci`。
3. 启动隔离开发后端；默认代理地址为 `http://127.0.0.1:8000`，可通过 `VITE_PROXY_TARGET` 覆盖。
4. 运行 `npm run dev`。首次管理员由后端 CLI 创建，前端不提供默认账号或公网初始化接口。

生产构建运行 `npm run build`，交付 `dist/`。Docker 镜像构建由项目部署目录负责，本目录不创建第二套后端容器配置。

## 子路径

`VITE_BASE_PATH` 是构建时配置，例如 `/automation/`。页面资产、hash 路由、API 前缀及鉴权产物下载保持同一应用前缀，后端配置需要一致。开发代理保留此前缀，不私自重写到其他服务。

登录令牌仅存当前页面内存；刷新需重新登录。节点令牌仅在登记后的当前窗口内用于下载连接文件，调用方令牌仅在创建时显示，页面不写入浏览器持久存储。下载的节点连接文件含凭据，需妥善保管并在导入后删除。日志和业务摘要均按文本显示。业务结果优先展示文字摘要及产物，原始协议记录可展开查看。

## 页面范围

项目切换与创建、总览、程序/版本/ZIP 上传封存、任务登记/手动触发、运行/日志/取消/核对/产物下载、节点维护、调用方授权、定时计划、批次文件交付、告警确认/关闭与通知连接、用户及成员角色、审计。

事件与定时共享后端参数和去重规则。手动触发请求在同一弹窗重试时保持 event_id。定时默认关闭，支持固定批次或等待标签二选一。调用方文件上传权限默认关闭。页面按钮控制仅为交互辅助，后端鉴权是最终边界。

表格按 50 条分页；表单资源选项按后端分页逐步读取，超过 10,000 项时明确报错并停止，避免无界读取。创建任务只读取所选程序的版本，不遍历请求所有程序版本。

## 验证

- `npm test`：Vitest + Vue Test Utils；HTTP 边界使用测试响应，测试不冒充真实后端联调。
- `npm run build`：类型检查和生产构建。
- `npm run format:check`：格式检查。
- `npm run test:e2e`：真实 Playwright 浏览器 + 已启动的本地隔离后端 + 本项目真实开发执行器。先提供 `WORKBENCH_E2E_SESSION` 指向本地测试会话文件（含 url、username、password），默认使用项目 `runtime/integration/session.local.json`。`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 可指定已安装 Chromium；否则使用 Playwright 默认浏览器。

E2E 限定 `127.0.0.1`，创建可识别合成测试记录，不连接真实业务接口，不创建或发送真实钉钉通知。它会调用项目 `.venv/Scripts/python.exe` 和 `agent --once` 运行无副作用 fixture。测试凭据不在命令行传递，临时节点凭据结束即删除。运行记录和合成数据留在独立测试 schema 中，由后端测试环境统一清理；不得把该脚本指向真实业务库。

截图和总结位于已忽略的 `e2e-results/`；密码和一次性凭据显示区域会遮罩。结果需结合实际命令及退出码阅读，不代表 CI、人工代码评审或生产发布审批通过。
