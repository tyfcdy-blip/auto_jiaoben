执行电脑与典型脚本测试：极简说明（服务器 rc.4）

一、执行电脑需要什么
1. Windows、Python 3.12，以及从当前服务器下载的“一键接入包”和“连接文件”。不需要Docker、Git或工作台源码。
2. 本机文件测试只需要Python标准库。打开网页、截图还需要Microsoft Edge和Playwright，安装到任务使用的Python环境里。
3. 开机并登录Windows，关闭自动睡眠。当前执行器是用户登录后自启动，不是无人登录也能启动的系统服务。

二、浏览器脚本准备一次运行环境
在执行电脑打开PowerShell（下面使用C:\workbench-demo为新建专用目录）：
  py -3.12 -m venv C:\workbench-demo\venv
  C:\workbench-demo\venv\Scripts\python.exe -m pip install -r requirements.txt
第二条命令须在本交付包解压目录执行（该目录含requirements.txt），或者将requirements.txt换成该文件完整路径。
此命令只需准备环境时执行，任务运行中不安装依赖。本包复用已安装Microsoft Edge，不需要下载Chromium。
如果py命令不存在，先确认Python3.12安装及启动器；可用实际Python3.12完整路径代替py -3.12。
Playwright是浏览器操作库，Apache-2.0许可证；微软Edge按其自身许可证使用。
参考：https://playwright.dev/python/docs/browsers

三、接入电脑
1. 登录 https://ai.muyaju.net/automation/ ，选择或创建独立测试项目。
2. 进入“执行电脑”→接入电脑：填电脑名称；工作台地址保留 https://ai.muyaju.net/automation 。
3. 运行环境选择Python，程序路径填 C:\workbench-demo\venv\Scripts\python.exe 。
4. 本次三个新示例不读取业务输入目录，因此不需要授予文件夹读取范围。以后用CSV/Excel目录程序时，单独授权测试根目录。
5. 下载“一键接入包”和“连接文件”，在执行电脑解压接入包，双击“安装并连接.cmd”，选择连接文件，核对后输入YES。
6. 返回页面确认在线。接入工具缺少自身依赖时也会联网安装。连接文件含节点凭据，接入后删除，不要转发。
7. 一台电脑登记一次即可，多项目共享时在“进入维护→配置电脑与项目”中授权，等待配置同步后结束维护。
8. 如果电脑已经接入，不要为每个程序重复安装执行器。确认已有Python运行时具备Playwright，或将浏览器程序绑定到已准备好的运行时。

四、上传三个程序
总交付ZIP解压后，每个以local-files、open-web、web-screenshot命名的ZIP是独立程序包，逐个上传；不要把总交付ZIP当成一个程序。
每个程序：程序库→接入程序→选择对应ZIP→运行环境Python→入口main.py→输入方式“常规参数 / 工作台文件批次”。
均启用必需结果报告，不勾选外部业务写入。高级设置的业务参数定义，复制对应parameter-schema.json完整内容。
程序包内的配置说明不会自动导入网页表单。填写并通过校验后发布。
创建任务时选择对应程序和这台在线电脑，运行超时建议90秒，不选择输入文件批次。
业务参数复制对应default-parameters.json。首轮使用默认参数即可，不需要真实业务文件。

五、三个示例的用途
local-files：在本次运行的输出目录内生成合成文本、复制文件、打ZIP并生成清单。用于验证本机文件读写、JSON结果和文件回传；不会移动、删除或覆盖用户业务文件。
open-web：打开独立Edge窗口，展示测试网页，读取标题并保存页面信息，短暂等待后自动关闭窗口。执行电脑要保持已登录桌面。
web-screenshot：后台打开测试网页，保存1280×720页面截图和页面信息JSON，生成成功通知正文。无需前台显示窗口。
默认网页是包内的离线合成测试页面，不使用真实账号。需要测试真实联网打开网页时，url只允许填 https://example.com/ （包括末尾斜杠）。其他网站不接受；以后由开发者对指定站点改包并单独验收。
截图只截网页可视区域，不是整个Windows桌面；不带登录态，不支持自动登录、表单提交或业务系统写入。
首轮为静态页面只读测试，JavaScript关闭并阻止非GET/HEAD请求；依赖JavaScript渲染的网站可能为空白，不代表截图链路故障。业务网站动态页面需另行适配验收。
使用已安装Microsoft Edge固定位置，不允许通过任务参数指定其他exe或共享文件夹程序。

六、运行和通知
生产服务器当前全局派发关闭：电脑可以上线，任务仍不会实际执行。完成连接/备份/钉钉准备后，由部署负责人按既有流程启用派发再做试跑。
在任务管理点击立即运行，运行中心观察排队→运行→成功，打开详情核对日志、JSON结果和下载文件。
截图发送：机器人连接配置Webhook及加签→发送测试消息并核对群内收到→启用机器人→通知规则的任务成功消息中选择截图任务和同项目机器人。
重新运行截图任务；成功后检查消息记录和钉钉群。群消息是文字和运行详情链接，需登录工作台查看、下载PNG；当前不直接上传图片附件，也不在群内展示图片。
脚本不持有钉钉密钥、不自行发送群消息。通知失败在消息记录排查，不要为重发消息反复运行业务脚本。
手动运行通过后，在任务上新增定时计划，核对时区、下次运行时间及参数，再启用计划。

七、常见问题
排队：检查全局派发、电脑在线/维护状态、同机其他运行、运行时是否匹配。
离线：检查电脑开机、Windows已登录、不休眠、执行器启动、服务器地址网络可达。
No module named playwright：依赖没有安装到“任务实际使用”的python.exe环境。不要只安装到另一个全局Python。
Edge无法启动：检查电脑已安装Edge、受单位策略限制情况、可视示例所需已登录桌面。非标准安装位置由电脑管理员及开发者核对，不能通过业务参数指定exe。
失败：先看运行日志和结构化失败摘要；超时会由平台终止执行进程树，结果文件可能来不及生成。
截图成功但群无消息：检查任务成功通知规则、机器人启用、消息记录；仅机器人测试成功不等于该任务已开启通知。

八、验收边界
本示例只证明执行电脑程序运行、文件回传与浏览器操作能力。真实服务器调度、实际电脑安装、真实钉钉送达由现场验收。
线上既有任务/数据库不由本测试包更改。项目代码中的19项folder_jobs测试用于先前CSV等四个示例，不能替代本套浏览器用例的结果。
