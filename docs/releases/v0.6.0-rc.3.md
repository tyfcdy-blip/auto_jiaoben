日期：2026-11-16。目标：按服务器现场地址`https://ai.muyaju.net/automation/`重新构建`linux/amd64`离线镜像，并固化镜像子路径核验。

- 运行环境`WB_BASE_PATH=/automation`、`WB_PUBLIC_BASE_URL=https://ai.muyaju.net`；
- 外部数据库网络为`muyaju-data-reservoir_database`，共享入口网络为`basic_basic_net`；
