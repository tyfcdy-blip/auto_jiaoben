# v0.6.0-rc.3 发布候选

日期：2026-11-16。目标：按服务器现场地址`https://ai.muyaju.net/automation/`重新构建`linux/amd64`离线镜像，并固化镜像子路径核验。

`v0.6.0-rc.2`的后端、外部PostgreSQL和网络拓扑验证有效，但离线镜像前端按根路径构建，首页引用`/assets/*`，不兼容现场`/automation/`，因此禁止部署且不覆盖原标签。rc.3必须满足：

- OCI version/revision与Git tag提交一致；
- 镜像平台为`linux/amd64`；
- 首页本地资源全部使用`/automation/assets/*`；
- 运行环境`WB_BASE_PATH=/automation`、`WB_PUBLIC_BASE_URL=https://ai.muyaju.net`；
- 外部数据库网络为`muyaju-data-reservoir_database`，共享入口网络为`basic_basic_net`；
- Docker加载后镜像ID不变，并记录离线包SHA-256。

服务器现场仍有容量阻断：`/data`仅余15GB、使用率93%。数据库账号/库、跨库拒绝、平台数据落盘位置、项目级备份恢复、共享Nginx审批及CentOS 7风险处置未完成前，不允许部署或正式派发。
