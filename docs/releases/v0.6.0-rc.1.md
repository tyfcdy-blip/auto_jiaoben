- 当前版本拒绝启用 `side_effects=true`，只能试点无外部写入程序；
- 业务密钥注入、生产级脚本账号隔离和外部写入恢复尚未完成；
- 真实服务器、生产域名/TLS、镜像仓库、异机备份、真实影刀/UNC和生产钉钉仍待验收；
- Git tag和本地镜像ID只能建立本地回滚依据，不能替代远端不可变RepoDigest；
- 最终镜像的Docker Scout扫描因当前未登录Docker账号而未执行；生产推送前仍须完成基础镜像和最终镜像CVE审查；
- 数据库结构变化后的回退必须使用匹配备份，不能仅切换镜像。

生产准备和逐项签署使用[生产部署单](../deployment/production-deployment-order.md)。
