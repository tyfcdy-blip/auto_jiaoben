# v0.6.0-rc.1 发布候选

日期：2026-11-16。定位：首次可回滚源码与镜像基线，用于服务器生产化准备和受控试点，不代表生产发布许可。

## 范围

- 账号、项目角色、程序版本、任务、计划、全局运行中心和共享执行电脑；
- Python/Node程序包上传、静态扫描、原包下载和不可变版本；
- 普通参数、拖拽/批次文件、执行电脑目录和UNC路径输入；
- Windows Agent心跳、领取、真实进程、日志、超时、取消、结果JSON和文件产物；
- 手动、定时和外部API触发；
- 系统告警、钉钉连接/策略/消息记录及脚本成功结果通知；
- Docker Compose、PostgreSQL、备份恢复工具和Windows一键接入包。

## 发布标识

- Git tag：`v0.6.0-rc.1`；
- 镜像tag：`automation-workbench:0.6.0-rc.1`；
- 完整commit与本地镜像ID：写入annotated tag及本次生成的离线清单；
- 远端RepoDigest：尚未生成，需在明确镜像仓库并获得推送授权后补入生产部署单。

## 验证结果

最终执行结果记录在[发布基线测试计划](../testing/release-baseline-plan.md)。本文件只引用实际结果，不把历史测试或未执行的生产步骤写成通过。

## 明确限制

- 当前版本拒绝启用 `side_effects=true`，只能试点无外部写入程序；
- 业务密钥注入、生产级脚本账号隔离和外部写入恢复尚未完成；
- 真实服务器、生产域名/TLS、镜像仓库、异机备份、真实影刀/UNC和生产钉钉仍待验收；
- Git tag和本地镜像ID只能建立本地回滚依据，不能替代远端不可变RepoDigest；
- 数据库结构变化后的回退必须使用匹配备份，不能仅切换镜像。

生产准备和逐项签署使用[生产部署单](../deployment/production-deployment-order.md)。
