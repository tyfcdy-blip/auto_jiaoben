# v0.5：nine离线业务试点

本版本新增 integrations/nine/ 中的包构建、接入入口、受控旧程序启动器及参数模式。只支持check和preflight，明确拒绝upload及execute额外参数；原nine源码未修改。

17个原程序/适配测试使用专用openpyxl环境与合成Excel，核对真实报表金额、预检22行、异常/空数据行为、取消、输入摘要和网络阻断。另2个真实平台联调经过调用方文件上传、冻结、触发/重复、PG持久受理、真实执行器、原程序、日志及产物鉴权下载。命令、退出码及结果见 [本地验证](../nine/verification.md) 与 [全平台验证](../nine/live-platform-verification.md)。

通用执行器的4个真实联调用例另覆盖同任务事件/定时带参、故障告警、运行中取消；不能据此声称真实影刀下载、nine自然定时周期或正式上传已经验收。

已确认原预检只检查结构，非法金额/日期在预检中可能仍退出0；适配结果明确标注结构预检、未上传，不把该结果升级为业务正确性证明。原报表会对对应错误退出失败，保留既有行为。

本版本离线切片通过不等于M5整体通过。正式上传仍须原manifest确认、固定节点/编号状态、真实服务端成功及幂等口径、业务授权与独立身份；当前禁止开启副作用执行。

Codex 自检通过不等于开发自测确认、人工代码评审、CI 验证或发布审批通过。
