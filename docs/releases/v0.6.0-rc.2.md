# v0.6.0-rc.2 发布候选

日期：2026-11-16。目标：在不启动第二套数据库的前提下，连接同机已有 PostgreSQL 17，并通过共享Docker Nginx提供独立HTTPS路径。

## 变更

- 自带PostgreSQL改为可选的`bundled-db` profile；开发模式保持启用。
- 新增外部数据库和共享Nginx Compose覆盖文件；API、Worker和初始化按最小网络范围接入。
- 数据库秘密由受控单行密码文件生成，支持特殊字符URL编码，不覆盖已有秘密。
- 数据库初始化只对可重试连接错误有限等待；错误凭据、结构和权限错误立即失败。
- API/Worker数据库连接池显式限额；服务器管理员还需设置账号连接上限。
- 内置备份恢复工具明确拒绝外部数据库模式，避免误操作共享实例。
- 生产部署单按现有服务器容器、卷、共享Nginx、离线镜像和容量事实更新。
