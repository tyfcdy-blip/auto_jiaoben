# 通知工作台拆分与脚本消息测试计划（2026-09-19）

执行模式：全过程开发。等级：L3；脚本结果协议新增可选字段，触达外部钉钉投递链路。基线 `main` 无首个提交，工作区文件均未跟踪；本次只改通知页面、结果协议、执行完成校验及对应测试/文档。当前本机 Docker 实例不作为开发测试数据源。

## 事实与边界

- 已有按项目授权的机器人连接、按连接告警类型规则、按任务成功结果开关及接收连接，以及两种带状态和重试的投递记录。
- 机器人凭据不传给脚本；平台仅在任务确认成功且结构化结果为 `success` 时按完成时配置入队。一个运行最多一条成功结果消息；系统失败仍由告警规则发送。
- 新增可选 `notification_text`，让脚本声明拟发送文本；未提供时沿用 `summary`。消息仍带任务和运行编号，并做现有凭据遮蔽。无配置、停用连接、失败结果均不外发脚本消息。
- 协议是可选扩展，旧程序继续运行；新程序写入该字段前必须升级对应执行电脑的执行器。当前在用执行器不会自动获得新校验协议。
- 暂不支持运行中任意次数主动发信、附件、@ 人、跨项目机器人或自定义任意模板。这些会改变消息数量与授权边界，需另行定义。
