# Windows执行电脑简化接入实施与测试计划

## 目标与边界

把现有“进入源码项目目录并手工运行命令”收敛为：在工作台登记电脑，下载连接文件和Windows接入包，解压后双击安装，选择连接文件，自动导入、后台启动并加入当前用户开机启动。

首版不保存人员账号密码，不申请管理员权限，不安装系统级Windows服务；开机启动发生在当前Windows用户登录后。执行器仍使用专用节点凭据，现有目录白名单、运行时和HTTPS规则保持不变。

## 工作包与验收

| 工作包 | 实现 | 验收 |
| --- | --- | --- |
| W1 接入包生成 | 后端从固定白名单打包Agent源码、协议、安装器和固定依赖清单 | 登录后可下载ZIP；匿名拒绝；包内无连接凭据、缓存或无关文件 |
| W2 Windows安装器 | 标准库安装器选择连接文件、复用可用Python、必要时创建独立环境、导入凭据、生成后台启动器 | 自定义测试目录真实安装；配置和令牌权限沿用现有校验；重复运行不覆盖凭据 |
| W3 自动运行 | 立即后台启动，可选写入当前用户Startup目录 | 测试使用隔离Startup目录，不修改真实系统启动项；生成文件不含令牌 |
| W4 前端引导 | 登记完成后分别下载一键接入包和连接文件，页面只保留三步 | 组件测试验证下载、错误和不重复签发节点 |
| W5 回归与资源 | 后端、Agent、前端测试和构建；测量真实空闲Agent | 关键用例通过；报告空闲内存和累计CPU，不宣称未测性能 |

## 风险与回滚

- 首次找不到已安装依赖时，需要联网从固定版本清单安装；失败不得写入开机启动。
- 当前用户未登录时不会启动，正式无人登录运行仍需后续受限Windows服务方案。
- 回滚时停用工作台节点并删除当前用户Startup中的对应启动文件；本次不自动执行卸载或删除用户数据。
