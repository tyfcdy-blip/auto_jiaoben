# 程序包、输入与外部接口改进测试计划

基线：`main`，仓库尚无首个提交，全部项目文件仍为未跟踪状态。执行模式：全过程开发。等级：L3；程序源码扫描、程序包下载、外部调用方令牌、文件上传和执行参数都属于安全或外部系统边界。

| 用例 | 工作包 | 层级 | 输入/前置 | 预期 | 实际 |
| --- | --- | --- | --- | --- | --- |
| PI01 | W1 程序包导出 | API | 有包版本、项目查看者 | 下载原始 ZIP，摘要不变，带审计记录 | 通过：原字节、响应头、查看者与审计断言通过 |
| PI02 | W1 越权与缺包 | API | 其他项目、节点令牌、无包版本 | 404/403，不能取得文件 | 通过：无关人员404、节点403、缺包404 |
| PI03 | W2 基础包校验 | 单元/API | 路径穿越、重复名、加密包、缺入口、压缩炸弹 | 阻断且不落盘 | 通过：存储安全回归纳入后端全量338项 |
| PI04 | W2 代码错误 | 单元/API | Python 语法错误、无效 JSON | 阻断上传，返回文件与行号 | 通过：预检与上传双重阻断 |
| PI05 | W2 高危能力 | 单元/API | 动态执行、shell、危险删除、不安全反序列化、硬编码秘密特征 | 高置信错误阻断；其他风险需管理员明确复核 | 通过：别名、明细截断绕过与CPU压测复验通过 |
| PI06 | W2 正常与多语言包 | 单元/API | 正常 Python、普通 JS/PowerShell、二进制依赖 | 不误判为安全证明；可上传并给出扫描覆盖说明 | 通过：不支持完整语法验证的入口明确要求人工复核 |
| PI07 | W3 参数表单 | 组件/API | string/number/integer/boolean/enum/array/必填/默认值 | 普通用户按字段填写并生成同等 JSON | 通过：含混合枚举、默认值和普通同名目录字段 |
| PI08 | W3 高级参数 | 组件 | 嵌套 object、无效 JSON、计划时间变量 | 可切换高级 JSON；错误不提交；时间变量保留 | 通过：组件与计划回归通过 |
| PI09 | W3 拖放文件运行 | 组件/API/集成 | 手动运行选择或拖入多个文件 | 建批次→逐文件上传→冻结→以 input_batch_id 触发 | 通过：多文件与上传期间参数竞态测试通过 |
| PI10 | W3 上传部分失败 | 组件/API | 网络中断、重名、超限、冻结冲突 | 不把部分上传当成功，可继续核对/重试 | 通过：共享交付状态机、容量配额与空批次恢复通过 |
| PI11 | W4 外部参数 | API/集成 | 调用方 token、任务 schema、parameters | 校验后持久化，并随 claim 下发执行电脑 | 通过：默认参数合并、标准JSON及claim断言通过 |
| PI12 | W4 外部文件夹 | API/集成 | input_dir/batch_key、授权目录 | 目录范围校验后下发，不复制源文件 | 通过：目录项目授权回归通过 |
| PI13 | W4 外部文件批次 | API/集成 | allow_input_upload、多个文件 | 创建/上传/冻结/触发/查询/下载全链路 | 通过：合成影刀全链路与跨调用方隔离通过 |
| PI14 | W4 页面说明 | 组件/浏览器 | 事件接入页面 | 说明“调用方不是新建 URL”，展示精确步骤、参数字段和文件方案 | 通过：组件断言及部署后资源文字核验通过 |
| PI15 | 总回归 | 全层级 | 合成数据、Docker PostgreSQL | Python、Vue、构建、静态检查、真实浏览器、容器健康通过 | 有条件通过：338后端、154前端、构建/Lint/格式/Compose、容器健康通过；真实影刀与真实业务文件未验证 |

扫描边界：静态扫描只能发现确定的包结构错误、受支持语言的语法错误和已定义风险特征，不能证明业务逻辑正确或程序绝对安全。二进制文件、动态生成代码、远程加载内容和运行时依赖仍需隔离执行、最小权限与人工审查。扫描不得执行上传代码或联网获取依赖。

退出条件：PI01–PI14 的适用自动化通过，无未关闭 P0/P1；真实业务程序、真实外部系统和生产部署未执行时必须标记未验证。回滚为恢复前一镜像；本轮不新增数据库列或数据迁移。
