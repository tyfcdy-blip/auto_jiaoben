# 影刀—工作台—脚本交付链路测试计划

本轮基线：`main`，仓库尚无首个提交，现有文件均为未跟踪文件。范围只含外部调用方触发/查询/下载、成功通知中的登录入口、导航分组与接入说明。钉钉真实发送、影刀软件内操作和生产部署不属于自动化测试；外部边界以合成调用方和钉钉 Mock 验证。

| 用例 | 需求/工作包 | 层级 | 输入与前置 | 预期 | 实际 |
| --- | --- | --- | --- | --- | --- |
| RH01 | M1/W1 菜单分组 | 组件/构建 | 已登录界面 | 输入文件、告警中心、消息记录独立于日常工作 | 通过 |
| RH02 | M2/W2 影刀触发 | API/集成 | 合成调用方、授权任务、稳定 event_id | 首次 202，重复 200 且同一 run_id | 通过 |
| RH03 | M2/W2 JSON 返回 | API/集成 | 合成执行器提交结果报告 | 调用方按 run_id 取得终态、结果 JSON 和产物清单 | 通过 |
| RH04 | M2/W2 文件交付 | API/集成 | 合成执行器上传产物 | 授权调用方取得完整字节；文件与运行不匹配返回 404 | 通过 |
| RH05 | M2/W2 权限 | API/集成 | 同项目另一调用方、其他项目、撤权、节点令牌 | 不能读取或下载未触发的运行，不能越权 | 通过 |
| RH06 | M3/W3 钉钉链接 | 单元/集成 | 配置 HTTPS 公网入口、成功结果通知 | 文本含登录后的运行详情入口；未配置时无猜测地址 | 通过（真实群链接未配置） |
| RH07 | M3/W3 地址校验 | 单元 | 非 HTTPS、路径/查询/凭据、子路径 | 拒绝不安全入口；合法子路径链接正确 | 通过 |
| RH08 | M4/W4 接入说明 | 文档/人工 | 影刀 HTTP 能力、调用方令牌、可访问目录 | 文档给出触发、查询、下载及失败处理可执行步骤 | 未验证 |
| RH09 | 总回归 | API/前端 | 现有合成数据 | 相关 Python/前端测试、静态检查、构建无回归 | 通过 |

准入：不连接真实业务系统、不用真实影刀文件和钉钉凭据。退出：RH01–RH07、RH09 自动化通过，RH08 的真实影刀配置步骤由业务电脑执行后补验。独立审查、真实钉钉群链接可达性和生产 HTTPS 地址仍须单独核对。失败时保持旧镜像/环境配置，不执行数据库迁移；本轮代码变更不改变持久化表结构。
