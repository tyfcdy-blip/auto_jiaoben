## 钉钉事实与边界

旧连接“测试机器人”的既有运行通知失败 5 次；任务后来才切换到“1111”，旧记录不会改绑或补发。2026-09-21 17:10:04，新连接“1111”的一条结果通知一次投递成功，表示钉钉 Webhook 返回成功；工作台无法证明客户端是否被折叠、群成员是否看到或连接是否指向预期群。真实群消息未由本轮测试主动发送。

当前 Docker 环境只绑定 `127.0.0.1:18080`，且 `WB_PUBLIC_BASE_URL` 为空，所以新通知暂不附带外部查看链接。上线需为工作台提供可从钉钉客户端访问的 HTTPS 根地址，再设置该变量。链接不含令牌，人员仍须登录并具有项目权限。
