# Excel 单页签合并工具实施与测试计划

日期：2026-09-17。执行模式：全过程开发。等级 L2：新增 Python 文件处理程序、第三方依赖打包、Excel 内容保留和工作台目录协议联动；不改平台数据库、权限、调度和生产配置。

## 目标与边界

输入是执行电脑可访问文件夹内的多个 `.xlsx` 文件，每个文件必须只有一个可见工作表。程序按相对文件名排序，把每个源工作表复制为输出工作簿的一个页签，输出 `合并结果.xlsx` 并通过工作台产物下载。源文件只读且运行后摘要不变。

页签按文件名命名；替换 Excel 禁止字符，超过31字符截断，忽略大小写后冲突自动添加序号。保存单元格值、普通公式与自引用、字体/填充/边框/对齐/数字格式、保护、批注、超链接、合并区域、行高列宽、隐藏/分组、冻结窗格、筛选、打印设置、数据验证和条件格式。

首版只接受 `.xlsx`。`.xls`、`.xlsm`、模板、密码保护、多页签、隐藏唯一页签、外部链接、表格对象、图表、图片、透视对象及加载警告明确失败，避免生成看似成功但内容缺失的文件。公式由 Excel 打开时重算；不计算或验证业务公式结果。上限50个源文件、输入合计50MiB、输出20MiB，与当前执行器产物限额保持一致。

程序 ZIP 自带固定 `openpyxl 3.1.5`、`et_xmlfile 2.0.0` 及 MIT 许可证；执行电脑只需 Python 3.12，不在任务运行时联网安装依赖。
