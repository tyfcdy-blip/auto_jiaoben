# 文件保留与容量保护测试计划

日期：2026-11-16。执行模式：全过程开发。任务等级：L3；原因是自动删除平台文件、生产容量门禁、后台调度和既有 PostgreSQL 结构兼容均属于高风险公共能力。

## 已确认规则

- 输入文件自上传时间起保留 45 天；运行输出自生成时间起保留 45 天。
- 程序包不自动删除；运行、审计和文件元数据继续保留。
- 仍被非终态运行、待核对运行或定时计划引用的输入不清理。
- 文件先标记为逻辑过期，再在确认不存在程序包或其他有效文件引用后删除物理对象。
- 生产平台文件物理占用达到 60 GiB，或写入后数据盘可用空间低于 30 GiB时拒绝新增文件；45 GiB开始报告容量预警。

## 准入、退出与回滚

准入条件是只使用临时目录、合成文件和隔离数据库；不连接生产数据库、不清理真实平台卷。退出条件是关键用例全部通过、无P0/P1、删除范围可证明只在`data_dir/objects`内、既有下载和执行链路回归通过。回滚必须同时回退应用镜像与数据库新增表；已清理的物理文件不能由镜像回退恢复，生产启用前必须完成平台文件备份与隔离恢复演练。
