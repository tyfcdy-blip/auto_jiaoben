## 问题、修复与风险

- 已修复：Windows原子保存的Office文件可能让路径状态和打开句柄返回不同ctime，导致合法输入误报变化。句柄校验现在比较身份、类型、链接数、大小和mtime；路径读取前后仍比较ctime。
- 已修复：部分Windows文件系统不会可靠更新目录时间，扫描过程中新增文件可能只靠目录时间无法发现。现在会再次枚举每个目录并比较文件名集合。
- 已简化：取消可选输出文件名，输出固定为 `合并结果.xlsx`，避免用户手写额外Schema或业务参数。
- 已修复：页签公式引用现在按Excel规则忽略大小写；工作表局部名称定义会明确拒绝；数据验证纯文本不被误改，条件格式复合公式可正确更新页签引用。
- 已加固：极端稀疏工作表在遍历前被拒绝；损坏XLSX返回结构化失败结果；目录二次枚举逐项限量并触发心跳。
- P0/P1：无未关闭项。
- P2：首版为保证不静默丢内容，会拒绝旧格式、宏、表格对象、图表、图片、透视、外部链接和名称定义；这是明确产品边界。
- 未验证：50个文件、50MiB输入和20MiB输出上限只验证了校验逻辑，未进行上限规模性能基准；钉钉通知不属于此工具，由工作台既有失败告警负责。
- 回滚：程序版本可在工作台停止使用并切回前一已发布版本；执行器和前端改动尚未部署。工具不修改源文件，无业务数据回滚步骤。
