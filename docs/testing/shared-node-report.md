## 重点用例

- 同一节点为两个项目轮流领取任务，项目持续有任务时按持久游标交替；节点总槽位为1。
- 未授权项目不能绑定节点；项目输入路径超出其授权子目录时，手动事件和计划均在服务端拒绝。
- 项目授权缩小或撤销后，已领取但未启动的旧尝试不能下载程序包或通过 `/started`。
- 已登记电脑可在维护状态下一次保存主机根目录和全部项目授权；遗漏既有授权、过期修订及并发旧表单均拒绝。
- Windows盘符大小写、相邻目录前缀及UNC边界按Windows规则判断。
- `D:/SyntheticInputs` 的配置摘要在服务端、Agent校验及重载后保持一致。
- 一个无关离线根不会阻塞另一个健康目录；项目A的清单不能越到项目B目录。
- 原项目管理员在节点共享后不能停用整台电脑或切换维护状态。
- 旧数据库缺少新增表时可新增、回填原项目授权，重复初始化不重复写入。
